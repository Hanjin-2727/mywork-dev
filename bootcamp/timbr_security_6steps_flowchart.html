STEP 01 Planning

데이터소스 정예화

이종 보안 로그(방화벽, IDS, SIEM, WAF)의 공통 키인 src_ip와 timestamp를 식별하고 정예 5대 테이블을 선별합니다.

STEP 02 DB Seeding

클라우드 DB 적재

Supabase PostgreSQL 17 security 스키마에 6개 테이블(총 6,812건)을 고속 적재하고 DBeaver에서 실시간 검증합니다.

STEP 03 Binding

온톨로지 바인딩

Timbr에서 bootcamp260909 온톨로지와 bootcamp 260909 데이터소스를 매칭하여 시맨틱 기반을 구축합니다.

STEP 04 Concept Modeling

개념 & 속성 모델링

firewall_log, ids_alert, siem_incident, waf_log 개념을 정의하고 가상 기본키와 라벨을 부여합니다.

STEP 05 Semantic Mapping

원샷 매핑 DDL

SQL Lab에서 원샷 DDL을 실행하여 테이블 ➡️ 개념 매핑과 함께 critical_siem_incident(위험도 70+) 하위 개념을 자동 생성합니다.

STEP 06 NL2SQL Demo

Data Agent NL2SQL

"위험 IP Top 5 보여줘" 같은 자연어 질문을 Timbr가 즉시 인식하고, 방화벽과 WAF를 교차 조인하는 푸시다운 SQL을 시연합니다.
