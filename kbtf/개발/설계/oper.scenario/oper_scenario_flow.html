W3C Decentralized Identity Operational Scenario

Custodial DID 기반 2-Track 주민증·수급카드 운영 시나리오

스마트폰(PWA + PASS + FIDO2 생체인증) vs 2G 피처폰(실물 NFC 목걸이 태그) 포용적 발급 체계

지갑 모델
Custodial (수탁형)
자격 체계
Dual-VC (분리 발급)

블록체인 내장 Custodial KMS

고령층의 키 분실 위험 0%. K-BTF 블록체인 내장 HSM에서 개인키 암호화 보관 및 대행 서명

낙인 방지 Dual-VC 분리 발급

주민증(거주증명)과 수급카드(무료식사권)를 분리하여 커뮤니티 활동 시 수급사실 미노출

공개키 0.05초 선확인 & 블록체인 사후 기록

센스 단말 내 공개키로 서명을 즉시 선확인하고, 사후 비동기 신호(Tx)로 블록체인 분산원장 영구 저장

1. 사용자 계층별 2-Track 채널 및 Custodial 매핑 아키텍처

Track A

스마트폰 사용자 (PWA 모바일 앱)

입주민의 약 60% 대상 (비대면 자율 발급)

  • 접근 방식: 웹 링크 또는 단지 내 QR 스캔을 통해 PWA 홈 화면 추가 (앱스토어 불필요)
  • 본인 확인: 통신 3사 PASS 간편인증 연동 $\rightarrow$ 암호화된 CI(연계정보 88B) 및 DI 확보
  • 로컬 보안: WebAuthn(FIDO2) 지문/FaceID 연동으로 단말기 잠금 및 Custodial 세션 토큰 인가
  • 지갑 형태: Custodial Web Wallet (KMS가 대행 서명하되 단말 생체인증이 마스터 스위치)
Track B

2G 피처폰 어르신 (실물 NFC 목걸이 카드)

디지털 소외계층 420세대 대상 (대면 창구 발급)

  • 접근 방식: 관리사무소 또는 산남종합사회복지관 현장 방문 시 즉시 실물 카드 수령
  • 본인 확인: 관리자 대면 신분증 확인 및 행정망(임대계약 DB + 사회보장정보망) 실시간 대조
  • 하드웨어 연동: 기성품 NFC 태그(ISO 14443A) 고유 UID를 어르신의 Custodial DID와 1:1 바인딩
  • 사용 편의: PIN 번호나 암호 없이 목에 걸고 배식구 리더기에 1초 대기만 하면 완료
Core Security Engine K-BTF Custodial KMS (Key Management Service) 구조
개인키 외부 유출 0%
1. 비식별 DID 생성

PASS CI 또는 주민번호 해시를 솔트와 단방향 해시화하여 비식별 난수 식별자 생성 (did:kbtf:resident:pseudo_uid)

2. KMS 암호화 보관

사용자별 Ed25519 서명 키쌍을 서버 HSM 보안 금고에 격리 보관. 인증 성공 시에만 메모리 상에서 대행 서명 수행

3. 온체인 원장 앵커링

블록체인 분산원장에는 실명, 동/호수 등 개인정보를 전면 배제하고 DID Document와 상태값만 불변 기록

2. 분리 발급되는 2종 Verifiable Credentials (Dual-VC) 구조

W3C VC Data Model v1.1 준수
1

공공임대 스마트 주민증 VC

ResidentCredential

정상 거주자격을 증명하는 디지털 신분증. 커뮤니티 활동, 폐쇄몰 중고거래, 입주자대표회의 투표에 사용됩니다.

주요 Claims 속성
issuer: "did:kbtf:issuer:housing_corp"
complexCode: "CJ-SANNAM-201" (산남주공2단지)
buildingNo: "204동" / unitNo: "502호"
occupancyStatus: "ACTIVE_RESIDENT"
leaseTerm: "2026-09-01_2028-08-31"
🛡️ 프라이버시 보호: 수급 여부 일체 미포함 유효기간 2년
2

취약계층 복지수급카드 VC

BeneficiaryDiningCredential

경로식당 무료급식 자격을 증명하는 복지 카드. 복지관 배식구 1초 태깅 및 지자체 국비 정산에 사용됩니다.

주요 Claims 속성
issuer: "did:kbtf:issuer:sannam_welfare"
welfareCategory: "BASIC_LIVELIHOOD" (생계급여)
diningEligibility: true (무료급식 대상)
dailyMealLimit: 1 (1일 1식 한도)
welfareCenterCode: "CJ-WELFARE-SN01"
🛡️ 프라이버시 보호: 동/호수 등 주거정보 미포함 유효기간 1년 (연차갱신)
