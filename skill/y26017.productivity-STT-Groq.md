## 📌 1. 개요 및 배경 (Executive Summary)

### 1.1 기존 로컬 음성 입력(`whisper.cpp`)의 치명적 한계
리눅스 데스크톱 환경에서 대표적인 음성 입력 도구인 **Vocalinux**를 기본 로컬 엔진(`whisper.cpp`)으로 구동할 경우, 일반 노트북(예: Intel Core i5 ULV, 내장 그래픽)에서 심각한 병목이 발생함:

1. **극심한 연산 지연 (Latency Bottleneck)**:
   - `medium` 모델 (769M): 4.5초 발화 시 추론 시간 **28.1초 소요 (RTF 6.28x)** ➔ 대화형 타이핑 불가능.
   - `small` 모델 (244M): 약 **6.0초 소요 (RTF 2.2x)**.
   - `base` 모델 (74M): 약 **5.6초 소요 (RTF 3.1x)** ➔ 내장 GPU(Intel UHD 620)의 메모리 버스 대역폭 한계로 5초 이하 단축 불가.
2. **한글 자모 엉킴 현상 (Sticky Input)**:
   - IBus 가상 키보드 입력 시 리눅스 한글 입력기(`ibus-hangul`)의 음절 조합 버퍼와 충돌하여 자모 분리(`ㅎㅏㄴㄱㅡㄹ`) 및 글자 겹침 발생.
3. **다국어 인식 한계**:
   - `"language": "ko"`로 하드코딩될 경우 영어를 발화해도 한글 발음으로 강제 변환되어 인식 불가.

### 1.2 Groq Cloud LPU 도입 효과
- **추론 속도 250ms (0.25초)**: 전용 LPU(Language Processing Unit) 텐서 아키텍처를 통해 발화가 끝나는 즉시 화면에 텍스트가 꽂히는 무지연 타이핑 구현.
- **세계 최고 성능 모델 (`whisper-large-v3-turbo`)**: 파라미터 800M+ 대형 모델이 클라우드에서 동작하여 한/영 복합 문장 및 개발 전문 용어 99% 정확도 달성.
- **노트북 리소스 0%**: CPU 점유율 0%, 팬 소음 제로, 발열 제로, 배터리 소모 극소화.
- **비용 100% 무료**: Groq Free Tier 제공 (신용카드 등록 불필요, 일 2,000회 요청 무료).

## 🔑 3. 4대 핵심 트러블슈팅 및 최적화 기법

| 문제점 (Problem) | 원인 (Root Cause) | 해결책 (Solution & Config) |
| :--- | :--- | :--- |
| **5초 ~ 28초 응답 지연** | 노트북 내장 GPU의 VRAM/버스 대역폭 한계 | `engine: "remote_api"`로 변경 후 **Groq LPU Cloud**로 오프로딩 |
| **한글 글자 엉킴/깨짐** | 가상 키 입력과 `ibus-hangul` 음절 조합 버퍼 충돌 | `"copy_to_clipboard": true` 설정 (클립보드 `Ctrl+V` 원샷 붙여넣기) |
| **영어 음성 인식 불능** | 엔진이 `"language": "ko"`로 하드코딩됨 | `"language": "auto"` 설정 및 한/영 복합 Primer 프롬프트 적용 |
| **말 끝난 후 대기 시간** | 기본 무음 판정 대기시간이 2초로 길게 설정됨 | `"silence_timeout": 0.5`로 단축 (말 끝나자마자 즉시 서버 전송) |

## 🛠️ 5. 데몬 관리 및 일상 사용 가이드

### 5.1 데몬 재시작 및 백그라운드 구동 스크립트
```bash
# 기존 프로세스 정리 및 락 파일 제거
killall -9 vocalinux 2>/dev/null || true
rm -f ~/.local/share/vocalinux/instance.lock

# 디스플레이 세션 환경변수와 함께 백그라운드 실행
env DISPLAY=:0 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus XAUTHORITY=~/.Xauthority \
nohup ~/.local/bin/vocalinux --start-minimized >/dev/null 2>&1 &
```

### 5.2 일상 사용 요령
- **음성 입력 시작**: **`Left Alt` 키를 빠르게 두 번 연타 (`Left Alt + Left Alt`)**
- **음성 입력 종료**:
  - **방법 ① (핸즈프리)**: 발화 후 **0.5초** 동안 침묵 유지 시 자동 종료 및 0.25초 만에 타이핑 완료.
  - **방법 ② (수동 토글)**: 발화 즉시 **`Left Alt + Left Alt`**를 다시 두 번 연타.
- **언어 자유 전환**:
  - 한국어로 말하면 ➔ 한국어로 자동 타이핑
  - 영어로 말하면 ➔ 영어로 자동 타이핑
