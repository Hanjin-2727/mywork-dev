  ──────
  ### 왜 Antigravity 2.0이 Claude Cowork와 같을까요?

  1. 에디터를 벗어난 협업 공간 (Beyond Code Editor)
      • 코드를 한 줄 한 줄 타이핑하는 개발자 화면(IDE)이 아니라,
      기획자·PM·개발자가 함께 프로젝트를 논의하고 지휘하는 **'업무 파트너
      전용 데스크톱 공간'**입니다.
  2. 아티팩트(Artifacts) 중심의 산출물 공유
      • 단순 채팅으로 끝나지 않고, 화면 우측에 제안서, 요구사항 정의서,
      Mermaid 다이어그램, 설계서 같은 구체적인 문서(Artifact)를 실시간으로
      띄워놓고 함께 수정·검토합니다.
  3. 업무 위임 및 자율 백그라운드 작업 (Multi-Agent & Tasks)
      • "시장 조사 및 벤치마킹 분석 보고서 작성해줘", "이 모듈 구조도
      설계해줘" 같은 큰 단위 업무를 맡기면, 에이전트가 백그라운드에서
      서브에이전트들을 띄워 병렬로 일을 처리하고 완료된 결과물을 취합해
      가져옵니다.
  4. 스케줄링 자동화 (Scheduled Tasks)
      • 정기 점검, 일일 업무 요약 등 주기적인 반복 업무를 등록해 두고
      비서처럼 관리할 수 있습니다.

  ──────
  ### 한 줄로 최종 정리하면
  • Antigravity 2.0 = Claude Cowork (프로젝트 기획, 제안서 작성, 업무 총괄
  지휘)
  • Antigravity IDE = Cursor (실제 소스 코드 타이핑 및 구현)
  • Antigravity CLI = Claude Code (터미널 단독 자율 실행 및 테스트)

  이 구조로 파악하시면 Antigravity 생태계를 가장 명확하게 활용하실 수
  있습니다!

  네, 말씀하신 그대로입니다! 개발 기획서·설계서 작성에 Antigravity 2.0이
  압도적으로 유리합니다.
  일반 챗봇이나 코드 에디터(IDE)와 달리, Antigravity 2.0이 개발 기획 단계에서
  강력한 이유는 크게 4가지입니다:
  ──────
  ### 1. 현실적인 코드베이스 분석 기반 기획
  일반 웹 챗봇은 실제 내 프로젝트의 상황을 모르고 허황된 기획을 내놓기
  쉽지만, Antigravity 2.0은 내 로컬 프로젝트의 기존 코드 구조, DB 스키마,
  사용 중인 라이브러리 버전을 직접 읽고 분석합니다.

  • *"우리 기존 유저 인증 모듈과 호환되는 소셜 로그인 기능 개발 기획서
  써줘"*라고 하면, 기존 코드를 분석하여 실제 구현 가능한 현실적인 설계를
  작성합니다.
  ──────
  ### 2. 아티팩트(Artifacts)와 시각 다이어그램 실시간 렌더링

  기획서에서 가장 중요한 다이어그램과 표를 우측 전용 뷰어에서 바로 시각화해
  줍니다.

  • 시스템 아키텍처 구조도 (flowchart)
  • API 호출 순서도 (sequenceDiagram)
  • 데이터베이스 테이블 구조 (erDiagram)
  • WBS / 일정 계획표
  채팅 줄글로 길게 늘어지는 대신, 발표나 보고용으로 바로 쓸 수 있는 깔끔한
  문서 형태로 완성됩니다.
  ──────
  ### 3. 병렬 리서치 에이전트(Subagents) 활용

  기획서를 쓸 때 필요한 시장 조사나 기술 검토를 서브에이전트에게 맡겨 동시에
  진행할 수 있습니다.

  • "A 라이브러리와 B 라이브러리의 장단점 벤치마킹 자료 조사해줘"
  • 메인 대화 맥락을 어지럽히지 않고 백그라운드에서 조사한 뒤, 핵심만
  기획서의 '기술 스택 선정 이유' 챕터에 깔끔하게 반영합니다.
  ──────
  ### 4. 기획에서 구현(IDE)으로 이어지는 '매끄러운 파이프라인'
