# 🚀 Google Antigravity 작업공간 권한 질문 생략 및 자동 실행 설정 가이드

> **문서명**: `y261016.AntiGrivSkipPermission.md`  
> **작성 일시**: 2026-10-16 20:15 (KST)  
> **대상 플랫폼**: Google Antigravity IDE (GUI) & Antigravity CLI (`agy`)  
> **핵심 목적**: 특정 작업공간(Workspace) 내에서 파일 수정, 도구 호출, 터미널 실행 시 매번 발생하는 권한 승인 팝업(Ask)을 비활성화하고 완전 자율 실행 모드로 운영하는 방법

---

## 📌 1. 개요 및 권한 평가 메커니즘

Google Antigravity는 보안을 위해 3단계 접근 제어(`Deny`, `Ask`, `Allow`)를 기본 적용합니다.  
지정된 신뢰 작업공간에서 반복적인 승인 질문 없이 자율적으로 태스크를 수행하도록 하려면 환경(GUI vs CLI)에 맞추어 다음 설정을 적용합니다.

---

## 🖥️ 2. Antigravity IDE / 데스크톱 앱 (GUI 환경)

### 2.1. 보안 프리셋 `Turbo` 모드 설정 (가장 추천)
1. IDE 상단 메뉴 또는 좌측 하단 톱니바퀴 아이콘 클릭:
   * **`Settings (설정)` ➔ `General` ➔ `Permission Settings`**
2. **Security Preset(보안 프리셋)**을 기본값(`Standard` / `Ask`)에서 **`Turbo`** (또는 `Unrestricted`)로 변경합니다.
3. **효과**: 신뢰된 작업공간 내부의 파일 생성·수정, 분석, 안전한 터미널 실행 시 매번 묻지 않고 자동으로 **Allow(승인)** 처리합니다.

### 2.2. 작업공간 신뢰 (Trust Workspace) 등록
* 신규 프로젝트 디렉터리를 열 때 나타나는 **"Trust this workspace / folder"** 대화창에서 **[Trust]**를 선택합니다.
* 특정 프로젝트별 세부 권한을 조정하려면:
  * **`Settings` ➔ `Projects` ➔ [해당 프로젝트 선택] ➔ `Scoped Permissions`**를 `Allow`로 설정합니다.

## 💻 3. Antigravity CLI (`agy` 터미널 환경)

CLI 환경에서 에이전트를 가동할 때는 시작 플래그 및 모드 설정을 통해 질문을 생략합니다.

### 3.1. 모든 권한 질문 생략 플래그 (`--dangerously-skip-permissions`)
```bash
agy --dangerously-skip-permissions
```
* 에이전트의 도구 호출, 파일 수정, 명령어 실행에 대한 모든 확인 프롬프트를 자동으로 승인합니다.

### 3.2. 자율 실행 모드 결합 (`--mode auto`)
```bash
agy --mode auto --dangerously-skip-permissions
```
* `--mode auto`: 에이전트가 편집 및 실행 계획을 스스로 수립하고 즉시 자동 반영합니다.
* `--mode accept-edits`: 코드 및 파일 편집 승인 단계만 자동으로 패스할 때 사용합니다.

### 3.3. 특정 작업공간 디렉터리를 지정하여 실행
```bash
agy --add-dir /home/tomkim/mywork-gov/kbtf --mode auto --dangerously-skip-permissions
```

## ⚙️ 4. 전역 설정 파일 영구 등록 (`settings.json`)

사용자 홈 디렉터리의 전역 설정 파일에 신뢰 작업공간을 영구적으로 등록하여 안전하게 권한을 상속시킵니다.

* **설정 파일 경로**: `~/.gemini/antigravity-cli/settings.json`

```json
{
  "allowNonWorkspaceAccess": true,
  "trustedWorkspaces": [
    "/home/tomkim",
    "/home/tomkim/mywork",
    "/home/tomkim/mywork-gov",
    "/home/tomkim/mywork-gov/kbtf"
  ]
}
```

## 💡 5. 빠른 추천 요약

| 사용 환경 | 추천 설정 방법 | 실행 명령 / 조치 |
| :--- | :--- | :--- |
| **GUI IDE** | 설정에서 Turbo 모드 활성화 | `Settings > Permission Settings > Turbo` 선택 |
| **CLI 쉘** | 무중단 완전 자율 모드로 세션 실행 | `agy --mode auto --dangerously-skip-permissions` |
| **CLI 재개** | 이전 세션을 이어서 권한 없이 재개 | `agy -c --dangerously-skip-permissions` |
