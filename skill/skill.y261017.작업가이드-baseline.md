      1) **GitHub**: `Obsidian Git` 플러그인(5분 자동 푸시 또는 터미널 커밋)을 통해 원격 Private Repo로 버전 관리 및 모바일 연동.
      2) **Google Drive**: 터미널에서 `save`(`smart-save`) 또는 `~/sync_vault_to_gdrive.sh`를 실행하여 Google Drive(`~/GoogleDrive/Obsidian Vault/`)로 미러링 동기화 및 NotebookLM 인식용 `.txt` 파일 자동 생성/공급.
    - **대용량 파일 처리 규약**:
      - 10MB 이상의 대용량 바이너리, 영상, 데이터셋 등은 GitHub 저장소에 직접 push하지 않고 `.gitignore` 처리 또는 Git LFS를 적용.
      - 대용량 원본 파일은 Google Drive 스토리지(`~/GoogleDrive/...`)에 직접 적재하고, 옵시디언 문서 내에는 해당 파일의 클라우드/로컬 링크를 기록하여 가볍고 빠른 Git 볼트 유지.
