# 이음오피스 기반 리눅스 HWP 편집 및 Gemini API 연동 가이드 (생산성 · 정부제안)

## 1. 개요 및 배경
- **배경**: 공공기관 및 정부지원사업 관련 HWP/HWPX 문서를 리눅스(Linux) 환경에서 편집하기 어렵고, AI와 협업 시 서식이 깨지는 문제를 해결하기 위함.
- **해결책**: 100% 무료 오픈소스 오피스인 **이음오피스(IEUM Office)**와 **Google Gemini API**를 연동하여 리눅스 환경에서의 HWP 원본 직접 편집 및 AI 라이브 협업 체계 구축.

---

## 2. 리눅스 환경에서의 이음오피스 활용성
1. **크로스플랫폼 지원**: Windows뿐만 아니라 Linux 및 Mac 환경을 지원하는 무료 오픈소스 오피스.
2. **HWP/HWPX 원본 직접 편집**: 한컴오피스 설치 없이 HWP, HWPX, PDF, Word, Excel 등의 원본 파일 포맷을 직접 열고 편집하여 저장 가능.
3. **주의사항 (베타 단계)**: 리눅스/맥 버전은 현재 베타(Beta) 상태이므로 중요 공문서 및 정부지원사업 계획서 작성 시 원본 백업본 유지 및 제출 전 호환성 검토 필요.

---

## 3. HWP 문서 - AI 에이전트 라이브 협업
1. **서식 보존 및 실시간 편집**: HWP 문서의 텍스트와 표 구조를 유지하면서 AI가 본문 윤문, 요약, 표 채우기, 수식 입력 등을 실시간 반영.
2. **원클릭 되돌리기(Undo)**: AI 편집 결과가 부적절할 경우 단 한 번의 Undo로 원본 상태 복구 가능.
3. **데이터 보안 유의**: AI 작업 시 문서 내용이 외부 구글 AI 서버로 전송되므로, 공공기관 기밀 정보나 개인정보가 포함된 문서는 주의 필요.

---

## 4. Gemini API 연동 vs Gemini Pro 웹 구독 비교
| 구분 | **Gemini Pro (gemini.google.com)** | **Gemini API (Google AI Studio)** |
| :--- | :--- | :--- |
| **서비스 성격** | 대화형 AI 소비자용 웹 서비스 | 외부 앱(이음오피스 등) 연동용 개발자 API |
| **비용 구조** | 월 정액 유료 구독 ($19.99/월 등) | **무료 API 키 제공** (무료 한도 소진 시 동작 멈춤, 유료 자동전환 없음) |
| **API 키 제공** | **미제공** (웹 구독으로 API 연동 불가) | **Google AI Studio(aistudio.google.com)에서 발급** |
| **이음오피스 연동** | 불가 | **가능** (이음오피스 [설정] -> API 키 입력란에 등록) |

---

## 5. 이음오피스 - Gemini API 연결 방법
1. **API 키 발급**: [Google AI Studio](https://aistudio.google.com) 접속 및 로그인 후 무료 Gemini API 키 생성.
2. **이음오피스 등록**: 이음오피스 실행 -> `[설정]` 메뉴 -> AI API 키 입력란에 발급받은 키 붙여넣기 및 저장.
3. **AI 도우미 활용**: 문서 편집 창 옆 AI 도우미 패널을 통해 열려 있는 HWP 문서 직접 수정 및 협업 진행.
